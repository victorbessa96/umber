# Licenses for bundled assets (`assets/`)

Umber ships a small starter library so a fresh install is never an empty
tool. This file inventories the licenses of everything under `assets/` that
this lane owns. Summary: **fonts are OFL-1.1; brushes, smart materials,
smart masks, and environment maps are original, authored in this repository,
and dedicated to the public domain under CC0.** No `.sbsar`, no
Adobe-derived content (the `ROADMAP.md` legal ruling stands).

## Fonts — SIL Open Font License 1.1

| File | Font | License |
| --- | --- | --- |
| `assets/fonts/Inter-Regular.ttf` | Inter (© 2016 The Inter Project Authors) | SIL OFL 1.1 — full text in `assets/fonts/OFL-Inter.txt` |
| `assets/fonts/JetBrainsMono-Regular.ttf` | JetBrains Mono (© 2020 The JetBrains Mono Project Authors) | SIL OFL 1.1 — full text in `assets/fonts/OFL-JetBrainsMono.txt` |

OFL 1.1 permits bundling and redistribution of the unmodified font files;
the license texts ship alongside the binaries as required.

## Brushes — CC0 (original, in-repo)

`assets/brushes/*.umberbrush` — 13 brush presets (hard/soft round,
airbrush, smudge, erasers, fill, detail, grunge, chisel, dry brush).
Authored for this project, no third-party source material. Dedicated to the
public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

## Smart materials and masks — CC0 (original, in-repo)

`assets/smart/*.umbersmart` (10 layer-stack materials) and
`assets/smart/*.umbermask` (5 effect-stack masks) are JSON presets authored
for this project — no Substance, no Adobe, no downloaded templates.
Dedicated to the public domain under CC0 1.0.

## Environment maps — CC0 (procedural, deterministic)

`assets/env/*.png` are **not** photographs or downloaded HDRIs. They are
generated by `assets/gen/make_studio_env.py` — pure stdlib Python
(struct + zlib + math, no RNG), so re-running the script reproduces each
PNG byte-for-byte:

- `assets/env/studio-neutral.png`
- `assets/env/studio-warm-key.png`
- `assets/env/studio-cool-fill.png`

All 1024×512 LDR (8-bit RGBA) equirects. Generated output of an original
script; dedicated to the public domain under CC0 1.0. Determinism is
pinned: `python3 assets/gen/make_studio_env.py --check` re-renders every
scene in memory and requires byte-identical output against the committed
PNGs (exit 0), without writing.

## Not covered by this file

`assets/icons/` and `assets/i18n/` are inventoried by their own lane; this
file makes no license claim for them.
