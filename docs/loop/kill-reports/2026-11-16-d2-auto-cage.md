## Summary

Implemented D2 auto-cage (baker power row, SPP census D2) per the design brief `docs/loop/briefs/2026-11-16-d2-auto-cage.md`. This adds CPU-side cage generation with three methods (Inflate, Shrinkwrap, Manual), GPU cage buffer upload, shader integration, panel UI, viewport cage wire overlay, and BakeSync persistence.

## Changes by Phase

### Phase 1: Cage Generator (CPU) - `crates/umber-mesh/src/bake_support.rs`

- Added `CageMethod` enum: `Inflate` (default), `Shrinkwrap`, `Manual`
- Added `Cage::from_high_low(high, low, method, front, back)` — per-vertex cage generation:
  - **Inflate**: Raycast from low vertex along normal toward high mesh; offset = hit_pos - low_pos; fallback to `front * normal` on miss
  - **Shrinkwrap**: Closest point on high mesh to low vertex; clamped to `[front, back]` range along normal
  - **Manual**: Returns `front * normal` (implicit cage, no raycast)
- Brute-force Möller–Trumbore per vertex (reuses `ray_intersect` constants: 1e-8 parallel eps, 1e-5 near clip)
- 5 new unit tests (kittest-first DoD):
  - `cage_from_high_low_inflate_matches_manual_on_flat` — flat surface: Inflate hits at surface (offset=0), Manual = front*normal
  - `cage_from_high_low_shrinkwrap_closer_than_inflate` — cavity test: Shrinkwrap magnitude ≤ Inflate
  - `cage_from_high_low_malformed_high_falls_back_to_manual` — empty high mesh → Manual fallback
  - `cage_from_high_low_inflate_produces_offsets_on_subdivided` — icosphere low vs scaled high → non-zero offsets
  - `cage_from_high_low_manual_is_exact_implicit` — Manual = front*normal exactly

- Added `closest_point_on_triangle` helper (Christer Ericson's algorithm)
- Exported `CageMethod`, `Cage` from `umber-mesh` crate

### Phase 2: GPU Cage Buffer + Shader

**`crates/umber-bake/src/transfer.rs`**
- `bake_transfer_mesh` now accepts `cage: Option<&Cage>`
- Cage buffer upload: `Vec<[f32;3]>` → `Vec<[f32;4]>` (16-byte aligned vec4)
- Dummy zero cage buffer when no cage provided (preserves v1 implicit cage behavior)
- Low mesh UVs buffer (binding 6, vec2<f32> per vertex)
- Low mesh triangle vertex indices buffer (binding 7, vec3<u32> per triangle)
- `TransferUniform` expanded: added `low_tri_count: u32` (36 bytes total, 16-byte aligned)
- Bind group layout entries for bindings 5, 6, 7
- Updated `uniform_for` signature to include `low_tri_count`

**`crates/umber-gpu/src/bake_shaders.rs`**
- `TRANSFER_BAKE_SHADER` updated:
  - Binding 5: `cage_offsets: array<vec4<f32>>`
  - Binding 6: `low_uvs: array<vec2<f32>>`
  - Binding 7: `low_tri_verts: array<vec3<u32>>`
  - `TransferParams` expanded with `low_tri_count`
  - `cs_main`: UV point-in-triangle search → barycentric weights → lerp cage offsets via `lerp3_cage` (matches `Cage::lerp_at` order: w,u,v)
  - Ray origin = `low_pos + normal * front_offset + cage_off`
  - Empty cage → zero buffer → no behavior change (v1 implicit cage preserved)
- Updated doc comment: "Cage support (D2 auto-cage)"

### Phase 3: Panel Wiring - `crates/umber-app/src/bakes_panel.rs`

**`HighPoly` struct**
- Added `auto_cage: bool` (default false)
- Added `cage_method: CageMethod` (default Inflate)

**UI (High-poly group)**
- Checkbox "Auto cage" (`bakes.auto-cage`) with hint (`bakes.auto-cage-hint`)
- Combo "Cage method" (`bakes.cage-method`) with options:
  - Inflate (`bakes.cage-method-inflate`)
  - Shrinkwrap (`bakes.cage-method-shrinkwrap`)
  - Manual (`bakes.cage-method-manual`)

**Bake flow**
- `bake_from_high`: if `auto_cage`, calls `Cage::from_high_low` with current `front`/`back`/`cage_method`
- Cage stored in `last_cage: Option<Cage>` for viewport overlay
- `TransferSource` now includes `cage: Option<Cage>`
- `BakeDispatch.transfer` type changed to `Option<(TransferSource, Option<Cage>)>`
- `bake_jobs` uses `std::mem::take` to extract transfer from mutable dispatch

**i18n keys added**
- `en-US.ftl`: `bakes.auto-cage`, `bakes.auto-cage-hint`, `bakes.cage-method`, `bakes.cage-method-inflate`, `bakes.cage-method-shrinkwrap`, `bakes.cage-method-manual`
- `pt-BR.ftl`: same keys translated

### Phase 4: Viewport Cage Wire Overlay

**`crates/umber-app/src/viewport.rs`**
- Added `cage_wire_buffer`, `cage_wire_count`, `cage_offsets` fields
- `set_cage_wire(gpu, mesh, cage_offsets)`: builds displaced wire buffer via `umber_mesh::cage_wire_vertices_from_indices`
- `clear_cage_wire()`: clears buffer on mesh unload
- `load_mesh` calls `clear_cage_wire()`
- Render: if cage buffer exists, uses `gpu.cage_wire_callback` with amber `WireColor::cage()`; fallback to regular wireframe in cage color if no cage buffer

**`crates/umber-mesh/src/overlay.rs`**
- Added `cage_wire_vertices_from_indices(mesh, cage_offsets)` — displaced wire vertices (`low_pos + cage_offset`)

**`crates/umber-gpu/src/renderer.rs`**
- Added dummy buffers for fallback bind groups (vertex, spec, view_mode, paint_params)
- `cage_wire_callback(uniform, cage_wire_buffer, cage_wire_count, uniform_buffer, color)` — returns `WireframePaintCallback` with cage wire buffer
- Added `MeshBuffers::uniform_buffer()` public getter

### Persistence
- `HighPoly` auto-cage and cage_method serialize via `BakeSync` (additive, `..Default::default()` on load)
- No project version bump needed
