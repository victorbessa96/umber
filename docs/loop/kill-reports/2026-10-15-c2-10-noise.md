# Kill report: C2-10, noise generators and mask anchors

Date: 2026-10-15. Author: dragon. Locks: `c2-10-noise` over
`crates/umber-app/src/document.rs`, and `c2-10-anchors-main` over
`crates/umber-app/src/main.rs` and the user guide. Closes the two items
left open after C2-10 v1.

## Built

- **`noise_perlin` generators bind without a bake.** The fill's own
  value-noise source (`FillSource::Noise`) stands in for the graph
  evaluator: `SMART_NOISE_SCALE` 8 and `SMART_NOISE_OCTAVES` 4. The seed
  comes from the layer id, so two applications differ while one layer
  stays stable across reloads. Worn metal's grunge layer now binds.
- **Mask anchors.** `compose_smart_mask` takes an `anchor(layer, channel)`
  source. The shell resolves the layer NAME in the active set's stack and
  reads that layer's OWN plane for the tile (`read_plane`). A missing
  anchor reads fully open (1.0, the mask slot's no-op) and is reported as
  `layer/channel`.
- The user guide covers both.

## Tests

- `a_noise_generator_binds_without_any_bake`: Worn metal's noise layer
  binds with no maps, at the documented scale and octaves.
- `an_anchor_stage_reads_the_named_layer_channel`: the anchor is asked
  once, by name; its red channel is the stage value; a missing anchor is
  open and reported.
- **Mutation check:** anchors that always read open fail the test.
- Gate 1: umber-app 531. Clippy's `type_complexity` was fixed with an
  `AnchorReads` alias.

## Decision recorded

An anchor reads the layer's own plane, not the prefix composite through
it (what material anchors read). A mask that keys off "where the Dirt
layer has paint" wants that layer's pixels, without the layers below
bleeding in.

## Follow-up: the per-texel lookup no longer hashes strings (lock `mask-compose-perf`, UNRUN)

Static review found `compose_smart_mask`'s per-texel closure did a
`BTreeMap` lookup keyed by CLONED strings for every anchor stage, on
every texel: 16.8M × (2 `String` clones + a tree walk) per anchor stage
on a 4K tile. Each stage's bytes are now resolved once into
`stage_bytes`; the closure finds its stage by `std::ptr::eq` on the
`&MaskSource` that `SmartMask::compose_scalar` passes (it iterates
`&self.ops`, the same storage as `mask.ops`, so the pointers match).
What remains per texel is a pointer scan over the 2–4 ops.

Semantics unchanged: a missing anchor reads open (1.0), a missing bake
0.5, constants pass through. The two composition tests pin all three
and must stay green; they have not run (host down). Not measured.
