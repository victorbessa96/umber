## 2. Judgment calls

Every call below is also written into the module docs of the file that
carries it.

- **Base stays in `TileTargets` (§1.4 unification deferred).**
  Unifying would churn every Base reader (save, export, bake, viewport
  binds) for no behavioral gain: `plane_of_mut`/`plane_thread`
  dispatch both stores, and the save census already walks both. A later
  move fills the seam without touching callers.
- **`eframe::wgpu` for encoder types.** `umber-app` has no direct wgpu
  dep (adding one is a `Cargo.toml` + lock change outside the lock) and
  bare `wgpu::` resolves only under the test target's dev-dependency.
  egui-wgpu 0.36 re-exports the workspace's single wgpu 30
  (`Cargo.lock` holds exactly one), so the types are identical.
- **No let-chains.** The kill gate formats with `--edition 2021`
  (verify-kill.sh), which cannot parse them (caught by rustfmt, not by
  reading — the workspace edition is 2021).
- **Composite errors drop dirt loudly.** A poisoned entry clears after
  one `warn` (no every-frame spam); the next write re-marks. Mask
  validation cannot fire from our resampled planes.
- **History-evict tombstone freeing deferred** (§5.4 item 5 — needs
  `UndoStack::iter` in umber-core, outside the lock). The 512 MiB cap
  bounds RAM; bytes are kept longer, so revives stay exact, never wrong.
- **Bake/export readers see the last flush** (one frame stale max).
  Their `Option<&PaintState>` signatures cannot flush (the Export
  dialog owner is outside the lock); the accessors resolve the
  composite, exact once frames settle.
- **`bake_sources` keeps shared signatures** (same reason — deviation
  from §4.1 part 3, documented in the module).
- **Stroke/save commit invalidation wired everywhere** (stage-2 gap
  found by reading the save loop: strokes/undo/resize never cleared
  `committed`, so an in-place save re-staged pre-write bytes — a
  stroke followed by save LOST the stroke). Every pixel write now
  clears it; resizes clear it too (old-size bytes would otherwise
  clean-skip past the resized plane).
- **Import decode via path-or-temp-file.** `read_png_rgba8` is
  path-based and `umber-app` has no direct PNG decoder (dependency
  change outside the lock). Bytes-only imports round-trip a temp file
  (counter-suffixed, deleted after). Row order: the reader yields GPU
  order — published directly, unlike sidecars (which store GPU order
  and flip back).
- **Fill budget badge in `document.rs`, material in `material_badges`.**
  The Layers rows render fills/dormancy/imports (no slot exists in
  `layers_panel.rs`, outside the lock); materials reuse Kill B's badge
  slot. The refusal/tombstone/budget *lines* live in the LayerStack
  panel (the status bar's snapshot is fixed).
- **Deleted tests are named, not silent:** 2b/2c (destructive publish),
  `fill_composites_like_any_layer` + the masked tail's composite half
  (destructive composite), `composite_material_channel` + `mask_plane`
  (consumerless seam). Their composite-level replacements are T5/T6/T7
  (stack), T12/T13 (plane + stack), and the masked-mask flush (T26).
- **End-stroke on a vanished non-paint owner retires as paint-kind.**
  The kind is unknowable to the session (no stack); preserving bytes
  loudly beats dropping them. Edge-of-edge (delete mid mask-stroke +
  undo); logged.
- **Warts 1–3 are closed** (order preserved — T5; re-eval idempotent —
  T6; hide/disable/delete unpublish, eval planes dropped — T7). No
  silent gaps: wart 4 (anchors) and instances stay v1-documented until
  stage 5, and the module docs say so.
