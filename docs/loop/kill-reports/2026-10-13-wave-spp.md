## What landed (30b966e)

umber-spp, a new L0-standalone crate (crates/spp, name umber-spp — the
member-path typo cost one confused hour: registered as crates/umber-spp,
built as crates/spp, and cargo's ENOENT pointed at the phantom path
while the real manifest read fine; `ls` settled it).

The reader implements EXACTLY the research doc's §6 (the doc is the
contract — docs/research/spp-hdf5-layout.md, committed 83aa242):
- Superblock v0-v3, signature at the 8 doublings, no offset/length
  width assumed.
- Object headers v1 + v2 (OHDR, 2-byte chunk sizes) + OCHK
  continuation blocks.
- The §6.3 message set: dataspaces v1/v2 (scalar + simple rank 1-3,
  max-dims-must-equal-dims), the strict datatype allow-list (u8/u16/
  i32-LE exact property bytes, f32/f64 IEEE-754 exact, fixed strings),
  layouts compact/contiguous/chunked (dims cross-checked), filter
  pipelines v1/v2 (deflate/shuffle/fletcher32 ONLY — deflate level
  ignored as opaque client data), links + compact groups, symbol-table
  groups (SNOD + local HEAP), attributes COUNTED not parsed.
- The §6.4 data decode: chunked assembly through v1 B-trees, per-chunk
  filter-mask bits honored, unshuffle by element size, raw inflate
  (flate2).
- §6.5: dense/fractal-heap groups report "dense-link group (not
  traversed)" — no speculative traversal.
- §6.6: everything out of subset is typed Unsupported/Corrupt, never
  a panic, never silent. Caps: 256 MiB payloads, depth 64.
- The model: version-stamp parse (§2, the minor-0 no-fallback rule),
  texture sets via H2 (top-level-group naming), channels via H1 (u16
  >>8 narrowing reported per channel, f32 clamps), HBO DETECTION only
  (the v11 marker 0x69000B11, the 12-byte magic 0x1B7C2FDD header,
  era labels) — every HBO dataset reports "not imported (HBO graph,
  era X)" per §5.8, never an error.
- The import report is first-class: every dataset reports with a
  reason + detail.

21 synthetic tests (the builder writes byte grids from the research
doc's own tables): round-trips, malformed inputs (typed, never panic),
HBO classification across all four eras, filter-mask honoring, u16
narrowing, channel-order branches, the §5.8 line shape.

## The repair trail (dispatch B's death + the battery's catches)

1. Truncated import line `use std::collections::{HashMap, HashSet;`
   (the claw's mid-write death) — one missing brace class.
2. The builder's deflate encoder: Compress::compress_vec with a
   zero-capacity Vec returns BufError on Finish — replaced with the
   stream encoder (flate2::write::DeflateEncoder). The claw had
   pinned the WRONG status in a debug_assert; the failing tests
   exposed it.
3. The §5.8 summary shape: the NotImported arm wrapped detail INSIDE
   the parens ("(HBO graph, era X; detail)"), breaking the contract
   line — now "(reason) — detail". Found by the probe: the contains
   check failed on a substring that LOOKED present.
4. The transpose test contradicted H1's own arm order ([2,1,2] IS
   H×W×C per the doc; the test's comment claimed channel-first) —
   rewritten to exercise both branches honestly.
5. The v2 fixture's string dataset declared shape [5] for a 5-byte
   scalar string (25-byte expectation vs 5 compact bytes) — scalar
   rank-0 dataspace.
6. Clippy: the needless_range_loop, the complex stamp type (alias),
   the genuinely-unused v2-dataspace builder (boundary-noted for the
   corpus follow-up).
