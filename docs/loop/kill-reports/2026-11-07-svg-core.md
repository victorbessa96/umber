## Judgment calls (claw's, dragon-reviewed)

- **Row-at-a-time supersampling, no 16x buffer**: the rasterizer keeps ~5×width bytes besides the output instead of a 16x f32 plane. Same 4x4 SSAA quality; the 2048² default cap stays (its original rationale was the big buffer, now documented honestly as conservative).
- **Cap check at the root tag**, inside `parse_document`, before any allocation — pin 4 holds structurally (`rasterize_svg` allocates the plane only after the parse passed).
- **Unknown elements skip their subtree**; `Unsupported` only for non-px units. Strict path data (no draw-up-to-error). `fill`/`fill-rule` invalid values inherit the parent. `width`/`height` rounded to nearest px; a lone dimension derives from viewBox aspect. `line` never covers (fill only). Root `svg` transform applied inside the viewBox mapping. Test 6 writes the 128 threshold as a literal because `stencil::ALPHA_CUT` is private (that file is outside the lock).
