## 2. Judgment calls

Every call below is also written into the module docs of the file that
carries it.

- **`stroke_owner` forced to `Base` on every accepted stage-3 stroke.**
  §2.3's end state snapshots `active_target`, but routing is unchanged
  (every batch stages into Base targets), so recording a `Layer` id would
  point at a plane the stroke never painted. T11's "lands in the begin-time
  owner" then holds at the pixel level, not just the field level. Stage 4
  switches the snapshot alongside the routing.
- **`sync_active_target` keeps `active_explicit` on a same-target push,
  clears it when the target moves.** The shell moves the target only when
  IT resolved it (open, new, vanished id), and a resolved target is auto by
  §2.3 — so explicit Base survives adds/removes/reorders while a vanished
  id's neighbour arrives auto, all through the spec's 3-arg signature.
- **`active_index` is meaningless for `Base`** (no stack index): preserved
  untouched; the vanished walk reads it only for `Layer` targets.
- **`stroke_refusal` is stored, not rendered.** The status line is
  `status_bar.rs`, outside this kill's lock — stage 4 wires the display.
  The refusal is exact today and the way out is one click (stated in docs).
- **Revalidation is a pure `document.rs` function; `main.rs` is glue.**
  The frame block is untestable headless (needs the shell); the decision
  table is fully pinned by `document.rs` tests instead.
- **The Base row always shows.** Tile-1001 Base baseColor is created in
  `PaintState::new`, so "non-empty stack OR Base holds any plane" is
  trivially true — no paint handle needed in `layers_ui`'s signature.
- **The ⧉ instance button does NOT select.** Selecting the new instance
  would refuse the very next stroke (explicit + unpaintable); add-selects
  cover the three add buttons only.
- **`PaintRefusal::Layer` displays as `"paint refused: {0}"`.**
- **`layer_mask_ui` sets target BEFORE mask** (`set_active_target` clears
  a foreign mask edit, so the order matters; deselect touches no target).
- **`Eq` on `InstanceError`** (needed by `PaintRefusal`'s derive; all
  fields qualify). Found by clippy, not by reading — §3's top risk below
  would have been a CI round-trip.
