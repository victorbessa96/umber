## Fix
- `umber_core::BlendMode` gained `pub const ALL: [BlendMode; 32]` and
  `pub fn label_key(self) -> &'static str` (kebab-case catalog key, never
  the Debug name). Core test pins ALL length, key uniqueness, kebab shape.
- Both catalogs gained a `blend =` section with all 32 painter-name
  labels (en + pt-BR), plus `tiles.none`, `brush.{color,save-as-label,
  new-preset-name,import-abr,abr-filter}`, `spp-import.extract-channels`
  ({ $count }), `status.pen-{windows-ink,wintab,wayland,x11,mouse}`,
  `overlays.filter-raster`, `graph.trust-load`.
- All call sites now route through `tr()` / `tr_args()`; the type-ahead
  in `document.rs` compares localized labels on both sides.
  `format_pen` maps each `InputSource` variant to its `status.pen-*` key;
  its test now asserts the localized label and that it is NOT the raw
  token.
- New guard test `i18n::tests::no_bare_english_ui_literals_in_sources`:
  scans crate sources for bare string literals (ASCII letter + space) in
  `.label("` / `.button("` / `.hint_text("` / `.add_filter("` /
  `.selected_text("` calls — glyph-only strings pass.
- New test `every_blend_mode_has_a_key_in_both_catalogs` resolves
  `blend.<label_key()>` for every `BlendMode::ALL` in en-US and pt-BR.
