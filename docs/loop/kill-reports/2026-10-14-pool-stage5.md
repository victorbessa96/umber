## 1. Built

**`crates/umber-app/src/paint_state.rs`**

- `resolve_composite_entries(snapshot, tile, channel, w, h, stop_after)` —
  the flush's entry builder EXTRACTED (byte-for-byte the same per-row
  rules, now in `resolve_row`) and shared with the anchor prefix, per
  §5.3's "the same entry builder the flush uses". `composite_dirty` calls
  it with `stop_after = None`, so the flush path is unchanged. The
  truncation is by ROW: a stop row with no plane, or no entry on that
  channel, still ends the prefix, so nothing above the anchor leaks in.
- `read_anchor_prefix(snapshot, tile, channel, anchor)` — the downward
  partial flatten on the CPU oracle [m11]: `read_plane` per prefix entry
  (each drains first, satisfying [M7]: a layer refreshed earlier this
  frame is read post-publish), folded by `composite_stack_cpu`. `None` for
  an anchor with no snapshot row (deleted). Plane-size mismatch → logged
  refusal.
- `row_is(row, who)`: row identity is Base-by-owner, layer-by-`layer_id`.
  Instance rows carry their SOURCE's owner, so owner equality would
  conflate them. `full_owners` now matches prev/next rows on
  `(owner, layer_id)` for the same reason.
- `layer_mask_event`: an instance's mask dirt lands on the SOURCE's
  `(tile, channel)`s (looked up through `last_snapshot`), which are the
  planes the instance's entry reads.
- Tests: T8 (`anchor(L0) = 200`, `anchor(L1) = 150`, bit-exact with
  `assert_eq`; deleted anchor → `None`; full-flatten sentinel ≈ M's 37);
  planeless-anchor-row truncation (an L2 above never leaks); instance
  render (CPU prefix through the instance 175, through the source 150;
  GPU flush 175 ±3, no-instance sentinel 150 refused).

**`crates/umber-app/src/main.rs`**

- `PaintMaterialIo` carries the frame's `CompositeSnapshot`; `anchor_image`
  calls `read_anchor_prefix`. The snapshot is built from the document with
  the real `base_visible` (the flush's rows, unmodified).
- `build_composite_snapshot` Instance arm: resolves the chain
  (`resolve_instance_source`, bounded by stack length so a corrupt cycle
  cannot hang the frame), emits a row with the SOURCE's owner and the
  instance's own visible/opacity/mask/id. A Paint/Fill source takes the
  instance's blend; a Material source keeps per-channel blends × the
  instance opacity. Dangling and Folder sources → no row.
- Tests: the snapshot test now pins the instance row (the old assert
  pinned v1's "no row" state and was updated to the stage-5 contract); a
  new chain/dangling/material-source test.

## 2. Judgment calls

- Anchors read the flush's rows UNMODIFIED, so hidden layers are skipped.
  I considered forcing every row visible ("an anchor names a layer's
  pixels") and rejected it: §5.3 says "the same entry builder the flush
  uses", and inventing a visibility rule would be an uncleared deviation.
  Named follow-up if artists find hide-to-look-underneath changing
  anchored materials surprising.
- `ForwardAnchor` checks positions in the material refresh's `layers`
  slice. An anchor on a layer absent from it passes the order check and
  fails loud at `anchor_image` (`None` → eval error), keeping the existing
  deleted-source contract.
- Instance mask dirt resolves its source through `last_snapshot` (the
  frame's truth). Before any flush, the fallback marks the instance's own
  (empty) planes, which is a no-op. Correct because no cache exists yet.
