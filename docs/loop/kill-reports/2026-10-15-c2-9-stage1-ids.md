# Kill report: C2-9 stage 1, one id space across a document's stacks

Date: 2026-10-15. Author: dragon. Lock: `c2-9-stage1-ids` over
`crates/umber-core/src/{layers,project}.rs` and this report. Design:
`docs/specs/per-set-stacks-design.md`, stage 1 (hazard 1: per-stack ids
collide in id-keyed paint planes).

## Built

`LayerStack::reserve_ids_from(floor)` raises the stack's id counter to at
least `floor` and never lowers it. It is the one core primitive per-set
stacks need. Before any set's stack allocates, the document raises it
to the document-wide max, so ids are globally unique and the paint
planes, keyed `(Layer(id), tile, channel)` with no set, stay correct
with no new dimension. `project.rs` needed no change: `from_parts`
already seeds with `max(saved counter, max id + 1)`.

## Test

`stacks_sharing_one_id_space_never_collide`:
- two stacks with interleaved adds, each raised first, give ids 0–4 with
  none shared;
- a stale floor never lowers a counter;
- a reloaded stack raised to the max allocates a fresh id.

The first run failed on my own wrong pin (expected 5 where A's counter is
correctly 3). It was re-pinned to the right value plus a second assert
for the raise. Gate 1: umber-core 108.
