## Built (`Document`)

- **`active_set` + `parked`**: the live set's stack, undo history and
  History log stay in the existing fields, so every caller of
  `doc.stack` / `doc.history` is unchanged. Every other set waits in
  `parked` as a `ParkedSet`.
- **`activate_set(name)`** parks the current set and swaps `name`'s in;
  a new set starts empty. Undo then acts on the active set only (Painter's
  per-set undo). The first activation ADOPTS a pre-set document's layers
  as that set's content, rather than parking them under a phantom ""
  name.
- **`load_sets(sets, active)`**, the Open path: activates `active` (or
  the first set if `active` is unknown) and parks the rest with fresh
  histories. Every stack is raised to the document-wide id floor.
- **`all_sets()`**: `(name, &stack)` for every set, sorted. Stage 3b's
  save and per-set snapshot read it.
- **`run` raises the live stack to the document-wide floor** (stage 1's
  `reserve_ids_from`) before every command, so ids never collide across
  sets.
- **Journal entries name the active set** when one is set; otherwise the
  attached set, as before.

## Tests (3)

- Switching keeps each stack, and ids are unique across sets. Undo in
  Body does not touch Hilt and vice versa. `all_sets` is sorted, and a
  same-set activate is a no-op.
- The first activation adopts the single-set document.
- `load_sets`: two saved stacks that both hold id 0 load without overlap,
  new ids collide with nothing, and an unknown active name falls back to
  the first set.
