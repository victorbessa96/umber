# Kill report: C2-11 the Brush panel rows for stamps, angle and jitter

Date: 2026-10-15. Author: dragon. Lock: `c2-11-panel` over
`crates/umber-app/src/brush_panel.rs`, both ftl catalogs and this report.
This closes C2-11: the engine (`47d8fed`), brush (`487fd49`) and jitter
(`90ec048`) halves had no UI until now.

## Built

- **The preset editor's stamp rows** (`stamp_rows`):
  - the **Bitmap stamp** checkbox;
  - once stamped, the **Stamp angle** combo: Unrotated / Fixed /
    Follow stroke / Random. Choosing a mode keeps its current kind
    (matched by discriminant), so picking Fixed twice does not reset
    the degrees;
  - an **Angle** field for Fixed and an **Offset** field for Follow
    stroke (±180°);
  - **the jitter quartet**: Size jitter (0–1), Angle jitter (0–180°),
    Scatter (0–2 radii) and Flow jitter (0–1), each defaulting to 0 with
    the property menu.

  The rows write the preset params, which the existing per-frame
  `sync_brush_params` carries into the session.
- **The session's Stamp image group** (`stamp_image_rows`): shows "None
  (a full square)" or the stamp's size, **Choose…** loads a PNG, and
  Reset clears it. The PNG becomes R8 coverage through `stamp_coverage`:
  Rec. 709 luma × alpha, so a white shape on transparency and a white
  shape on black both stamp the shape. A refused or unreadable file is
  logged; the stamp is unchanged.
- 15 new keys in BOTH catalogs (`brush.stamped`, `.stamp-angle`,
  `.angle-*`, `.jitter-*`, `.stamp-image`, `.stamp-none`). Choose and
  Reset reuse the `button.*` keys.
