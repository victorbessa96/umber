## Built

- **Per-set channel lists:**
  - `MeshMapImportState::switch_set(name, parked)` parks the active
    `TextureSet` (its user channels kept) and restores `name`'s, or a
    default set if `name` is new;
  - `AppState.parked_texture_sets` holds them, and the shell's set switch
    calls it beside `doc.activate_set`;
  - the save writes each parked set's own channel list (stage 3b wrote
    defaults), and the open parks every non-active set's saved list;
  - File ▸ New clears them.
- **The Layers panel header** names the active set (`layers.set-header`,
  both catalogs) whenever the document has one.
- **The user guide** gains the texture-sets paragraph, and the stale
  "two undo timelines" gap is replaced by the C2-7 behavior.
