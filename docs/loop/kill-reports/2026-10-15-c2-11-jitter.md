## Built

- **`Jitter { size, angle_degrees, position, flow }`** on
  `BrushParams.jitter`, `#[serde(default)]` = all zero = no jitter, so
  pre-jitter presets paint exactly as before. Ranges are clamped and
  non-finite values become zero:
  - size: ± fraction of the radius, 0..=1;
  - angle: ± degrees, 0..=180;
  - position: up to N radii in a random direction, 0..=2;
  - flow: reduces the alpha by up to the fraction, 0..=1. It only ever
    thins a dab.
- **Deterministic**: four samples per dab come from a salted FNV-1a hash
  of the dab's PLANNED position, with a final avalanche so neighbouring
  dabs decorrelate. The same stroke always jitters the same, which keeps
  undo/redo and replay byte-stable, the same rule as
  `StampAngle::Random`. No RNG state is threaded through the adapter.
- The angle jitter adds to the stamp angle; it is inert on radial dabs,
  which are rotation-symmetric.
- **The zero-jitter path short-circuits** (`is_none`) and builds the dab
  exactly as before.

## Tests

`no_jitter_is_unchanged_and_jitter_stays_in_range`:
- zero jitter keeps every position and the radius;
- the same jitter run twice gives identical dabs;
- every jittered dab stays inside its documented ranges (radius within
  ±50%, offset ≤ 1 radius, alpha in [½, 1]× the unjittered alpha,
  angle within ±30°);
- at least 3 of 4 dabs actually vary;
- the clamp maps 9 / NaN / −3 / 2 to 1 / 0 / 0 / 1.

**Mutation check:** disabling the jitter branch fails it at "jitter
actually varies the dabs".

## Judgment calls

- **The position distance reuses the size sample's magnitude** rather
  than a fifth salt. Visually it is indistinguishable. Named in the code.
- **Flow only thins.** A flow jitter that could exceed the dab alpha
  would break wash mode's opacity ceiling (`opaque_linearize`).
