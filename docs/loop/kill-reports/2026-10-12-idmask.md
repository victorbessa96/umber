# Kill report — ID-mask selection (C1 worklist #11, 2026-10-12)

## What landed

Click a mesh region → only that baked ID receives paint afterward.
Selection-time mask: the active set's `QuickMask` plane is filled `1.0`
where the ID bake equals the clicked texel's ID, `0.0` elsewhere, and
gating arms. `LayerMask` (`umber-core` `layers.rs`) untouched
(metadata-only by design).

## Gesture path (click → bake read → coverage → gate)

1. **Strip tool** — `ToolKind::IdMask` (`umber-app` `toolbar.rs`: `ALL`,
   `icon()` = `square-dashed`, `label()` = `tr("brush.tool-id-mask")`
   + en-US/pt-BR keys). Strip-only like Pick: `BrushPanel::select_tool`
   keeps the last real brush; no shortcut key (mouse-only, like Pick).
2. **Viewport arm** — shell syncs `Viewport::set_idmask_armed` from the
   strip each frame (`main.rs`, next to the pick sync). While armed, a
   primary click returns `ViewportClick::IdMask(uv)` via the existing
   `pick_uv` raycast; painting is suppressed; a miss falls through to
   orbit.
3. **Bake read** — shell calls
   `PaintState::bake_and_select_id(mesh, uv)` (`paint_state.rs`), which
   routes the tile, runs `umber_bake::id::bake_id_mesh` (Triangle flavor)
   at the tile's set size, then selects.
4. **Coverage** — `umber_brush::id_mask::select_id` (`id_mask.rs`):
   nearest texel under the bake's texel-center V-flipped convention
   (`x = round(u·w − 0.5)`, `y = round((1−v)·h − 0.5)`), whole-ID
   4-byte equality fill through `QuickMask::replace_plane` (exact
   `1.0`/`0.0`, invert parity reset), `set_active(true)` +
   `set_editing(false)` so `gates()` holds. Refusals (untouched mask):
   empty bake, length mismatch, bake≠mask size, uncovered click.
5. **Gate** — the existing plumbing does the rest: `select_id_mask`
   drops only that tile's `mask_synced` flag, so the next gated dab
   uploads the fresh plane (`sync_mask_tile`) before staging with
   `with_mask_gate(true)`; mid-stroke selection refused
   (`IdSelectError::StrokeInFlight`, same rule as invert/clear).

## Tests (7 new)

- `umber-brush` `id_mask.rs` (5, headless): exact A-in/B-out fill +
  arming; replacement selects B; uncovered click errors with the mask
  untouched; size/dimension mismatches error; invert-parity reset +
  NaN-UV floor.
- `umber-brush` `quick_mask.rs` (1, headless): `replace_plane` writes
  wholesale, resets parity, refuses bad lengths.
- `umber-app` `paint_state.rs` (2, GPU with graceful skip): on a
  two-triangle split-halves bake, `select_id_mask` returns the FNV-1a
  golden of triangle 0 (`[0x15, 0xF5, 0x95, 255]`, pinned against the
  bake's own mirror) with a byte-exact plane, and `bake_and_select_id`
  agrees; a gated stroke then changes ONLY clicked-ID texels
  (`stroke_mask_gate` asserted true, region-B texel byte-identical),
  and both entry points refuse mid-stroke.

## Deferred (recorded in module docs)

- **Cached bake**: every click re-bakes the full set size (16M texels at
  the 4K default). Bake-on-tool-entry + re-bake-on-mesh-change is the
  named follow-up; no new global store was invented for v1.
- **Multi-tile**: the bake spans the `0..1` UV frame; selection fills
  the clicked tile's plane only. Per-tile bakes for UDIM deferred.
- **Multi-ID selection** (shift-click to add): single-ID replace only.
- **Full mask stacks** (grayscale/bitmap paint masks, mask + effects):
  the requirements §2 row keeps its ✗-as-marked prefix; only the
  selection-time cell is marked ✓ built (`PENDING`).
