# Kill report: C2-22, the Windows code signing decision

Date: 2026-10-15. Author: dragon. Lock: `c2-22-signing` over README.md,
`docs/CODE_SIGNING.md`, the release checklist and this report. Decided by
Bessa ("approved to follow on everything following your suggestions").

## Decision

Ship the alpha unsigned, documented; apply to SignPath Foundation's free
open-source signing.

## The options checked (Microsoft Learn, 2026-10-15)

| option | cost | SmartScreen | for Umber |
|---|---|---|---|
| Azure Artifact Signing | $9.99/mo | reputation builds | no: individuals US/Canada only; orgs US/CA/EU/UK |
| OV certificate | $150–300/yr | reputation builds | fallback |
| EV certificate | $400+/yr | same as OV since 2024 | not worth it |
| SignPath Foundation (OSS) | free | reputation builds | **apply** |
| unsigned + checksums | free | "protected your PC" | the alpha |

## SignPath's conditions, checked against the repo

| condition | state |
|---|---|
| OSI license, no commercial dual-license | GPL-3.0-or-later; `LICENSE` is byte-identical to gnu.org's text (md5 `1ebbd3e3…`); GitHub's license API reports `GPL-3.0` |
| No proprietary components | none known |
| Built from source in a verifiable way | `release.yml` on GitHub Actions from the tag |
| Already released in the signed form | **not yet**: the alpha tag provides it |
| "Code signing policy" on home + release pages | README section + `docs/CODE_SIGNING.md` (this kill) |
| Roles, privacy line, uninstall | in `CODE_SIGNING.md`: owner = approver; the exact privacy sentence; per-user installer changes + uninstall |
| MFA on GitHub + SignPath | **Bessa** must confirm GitHub MFA (I cannot see it) |
| Product name/version metadata on signed binaries | open: Windows version resources (`winres`/`embed-resource`) are a release-config kill |

The claims in `CODE_SIGNING.md` were checked against the sources:

- No networking crate anywhere: no `std::net`, ureq, reqwest or hyper in
  the sources or Cargo.lock. "No telemetry" is true.
- The installer behaviour (`~/.cargo/bin`, the PATH edit and its opt-out
  `UMBER_APP_NO_MODIFY_PATH`, the receipt) is read from cargo-dist
  0.32.0's own templates and schema in the registry.
