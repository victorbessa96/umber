## Build (dispatch-time lock: `razul-d2-auto-cage`)

1. **Cage generator (CPU)**: Add `Cage::from_high_low(high: &MeshData, low: &MeshData, method: CageMethod, front: f32, back: f32) -> Cage` in `bake_support.rs`.  
   - `CageMethod` enum: `Inflate` (raycast from low vertex along normal to high mesh, offset = hit - low_pos), `Shrinkwrap` (closest point on high mesh), `Manual` (no-op, returns default offsets = `front * normal`).  
   - Per-vertex: cast ray `low_pos + normal * front` → `-normal` against high triangles; first hit within `[0, front + back]` sets offset; miss → `front * normal` (the current implicit cage).  
   - Reuse `ray_intersect` from `umber_mesh::raycast` (same Möller–Trumbore constants). No BVH in v1 — brute-force per vertex, acceptable for ≤10k low vertices (matches transfer's per-texel brute force).  
   - Unit test: icosphere low (42 verts) vs subdivided high; `Inflate` produces non-zero offsets; `Manual` produces `front * normal` exactly; malformed high → `Manual` fallback, never panic.

2. **GPU cage buffer + shader**:  
   - New WGSL binding in `TRANSFER_BAKE_SHADER` (`bake_shaders.rs`): `@group(0) @binding(5) var<storage, read> cage_offsets: array<vec3<f32>>;` (one `vec3` per low vertex, 12 bytes, packed to 16-byte alignment via `vec4` if needed — match `GpuTriangle` precedent).  
   - `TransferUniform` grows by 4 bytes (pad) or add `cage_vertex_count: u32`; keep 16-byte alignment.  
   - In `cs_main`: after `low_pos`/`low_normal` load, `var cage_off = cage_offsets[vertex_index];` (vertex index from barycentric interpolation — the position map's triangle ID gives the three vertex indices; lerp with same weights as `Cage::lerp_at`). Ray origin = `low_pos + low_normal * params.front_offset + cage_off`.  
   - `transfer.rs`: upload `Cage.offsets` as `Vec<[f32; 3]>` → storage buffer (binding 5); bind only when `Cage` is non-empty (offsets.len() == low.vertex_count()). Empty cage → skip buffer, shader reads zeros (current behavior).

3. **Panel wiring**:  
   - Add `auto_cage: bool` to `HighPoly` (default `false` — matches `show_cage` default-off contract).  
   - Add `cage_method: CageMethod` to `HighPoly` (default `Inflate`).  
   - UI: checkbox "Auto cage" (`bakes.auto-cage`) + combo `Inflate`/`Shrinkwrap`/`Manual` (`bakes.cage-method`) in High-poly group, below front/back sliders.  
   - On `bake_from_high`: if `auto_cage`, call `Cage::from_high_low` with current `front`/`back` + `cage_method`; pass `Cage` to `bake_transfer_mesh` (new optional param).  
   - `show_cage` overlay (viewport wireframe) draws the generated cage when enabled — reuse existing `WireColor::cage()`; vertex positions = `low_pos + cage_offset` per vertex, indexed by low mesh topology.

4. **Persistence**: `HighPoly` serializes via `BakeSync` (R-D1 pattern) — new fields are additive, `..Default::default()` on load. No project version bump.

## Kittest-first definition of done

- `cage_from_high_low_inflate_matches_manual_on_flat`: plane low vs plane high (same plane) → resolved contract (2026-11-18, cross-review D2 MED): cage offset = `hit − low_pos` (miss → `front * normal`) and the shader ray origin is `low_pos + n*front_offset + cage_off`. On flat geometry Inflate's ray from `low_pos + front*n` along `-n` hits at `t = front` → hit = `low_pos` → offset 0, so its ray origin coincides with the no-cage v1 origin and the transfer output is byte-equal to auto-cage-off; Manual returns `front * normal` by design. The test asserts the per-method offsets and the Inflate==v1-origin equality.
- `cage_from_high_low_shrinkwrap_closer_than_inflate`: low vertex inside high cavity → `Shrinkwrap` offset magnitude < `Inflate` (ray misses cavity, hits far wall).
- `transfer_shader_cage_lerp_matches_cpu`: same low triangle + barycentric weights → GPU `cage_off` == CPU `Cage::lerp_at` (bit-identical, IEEE `*` commutative, sum order unchanged — same property as `lerp3` at `bake_support.rs:72`).
- `auto_cage_off_is_byte_identical_to_today`: `auto_cage = false` + `front=0.1, back=0.1` → transfer output matches current v1 (implicit cage) pixel-for-pixel.
- `cage_overlay_shows_generated`: viewport `show_cage = true` after auto-cage bake → wireframe draws displaced vertices (visual smoke, not pixel test).

## Rejected alternatives

| Alternative | Reason |
|-------------|--------|
| Per-texel cage in shader (no CPU buffer) | Would need high mesh in shader (already have triangle buffer) + per-texel raycast to compute offset — doubles ray cost; CPU generator is O(low_verts × high_tris) once, not per texel. |
| BVH for cage generation | v1 scope: low vert count ≤10k, high tris ≤8k (MAX_TRIS_PER_BAKE). Brute force = 80M tests max, ~0.2 s on modern CPU. BVH is D3+ perf work. |
| Cage as vertex attribute in position map | Position map is LOW mesh UV raster; cage is per-LOW-vertex. Adding to position map conflates two passes; storage buffer is cleaner and matches transfer's existing bind-group shape. |
| Unified cage for all bake kinds | Transfer is the only cross-mesh bake (AO/curvature/normal/position/thickness/ID/skew are self-bakes). Cage only matters for transfer. |
