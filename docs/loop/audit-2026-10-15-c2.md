# Umber gap audit C2 (2026-10-15): what is still missing

Date: 2026-10-15. Author: dragon, with two read-only investigator
subagents (painter workflow; release readiness). Every row's evidence was
spot-checked against the tree at `163e9fe` before landing here (the eight
highest-severity claims re-grepped by hand; all held). Supersedes the C1
audit's worklist (`audit-2026-10-12-c1.md`, all 22 items done) as the
active queue source.

## The headline

The engine is broad and the GUI plan is moving, but **a painter cannot
finish a real PBR asset in the GUI today**:

1. **Painting only reaches Base Color.** The paint session has
   `set_active_channel` (`umber-paint/src/paint_state.rs:1499`), but no
   app code calls it, so roughness, metallic, height and normal cannot be
   painted.
2. **Export writes Base Color only from paint.** "V1 painted scope is Base
   Color ONLY" (`umber-app/src/export_dialog.rs:33`). Every other painted
   channel is filtered out of the presets.
3. **Layers can be added and deleted, but not reordered, renamed,
   re-blended or given opacity from the UI.** The core commands exist
   (`umber-core/src/layers.rs` `LayerCommand::{Reorder, Rename,
   SetOpacity, SetBlendMode}`), but app code calls them only from tests.
   There is no Duplicate and no folder creation.
4. **Two undo timelines.** Ctrl+Z reaches only `Document::undo`
   (`main.rs:1356`). Paint strokes undo only from the History panel's own
   buttons. Mask strokes and graph edits are not undoable at all.
5. **Work is lost silently.** There is no quit guard (no
   `close_requested` / `CancelClose` anywhere). The journal records
   layer-metadata ops only, never pixels (`umber-core/src/journal.rs:11`).
   A never-saved document is not journaled. There is no panic hook and no
   recovery prompt.
6. **One layer stack per document** (`document.rs:23`). A
   multi-texture-set asset loses every set's layers but the active one on
   save.

These six are the next audit cycle's priority, ahead of any remaining GUI
polish.

## What the audit did NOT find (stated so it is not re-hunted)

- The mesh importers are well hunted: FBX, glTF, OBJ, USDA, USDC and USDZ
  all have noise and mutation coverage. The gap there is a real-file
  corpus and a coverage-guided fuzzer, which is Tier 6-level, not a hole.
- The plugin sandbox has fuel, a 64 MiB memory cap and a fresh store per
  call. SECURITY.md is accurate about what exists.
