## Wave 1 — the primitive bug (CORRECTNESS, the highest blast radius)

**Why first:** `UvTri::bary` is THE texel→barycentric authority for the
whole crate (row 156-B). The GPU bake shader mirrors it. Every consumer
inherits its blind spot. One kill here fixes the projector, the fill,
the bakes, the export padding and the GPU at once.

### 1.1 `UvTri` conditioning — the per-triangle rule

- **Surface:** `crates/umber-mesh/src/uv_gbuffer.rs` +
  `crates/umber-gpu/src/bake_shaders.rs` (the shader's mirror) +
  `crates/umber-bake/src/gbuffer.rs` (the parity goldens).
- **The change:** a triangle whose normalized area
  (`|area| / longest_edge²`) is below **1e-6** is not a valid
  footprint. It covers nothing, on the CPU and on the GPU alike.
- **Measured (probe under `~/.hermes/cache/scratch/probe-raster-cost/`):**
  garbage claims 272 → **0**; the point lookup and the windowed walk's
  texel sets now agree EXACTLY (set diff 31 → **0**); grids **0/10 912**
  and random triangles **0/4 263** rejected at the 1e-6 threshold; the
  only coverage lost is the degenerate needles themselves.
- **Rejected alternatives (do not re-derive):** the per-point upper
  bound (`b_i <= 1 + eps`) makes it WORSE (lost claims 7→16, set diff
  31→54); a per-point reconstruction tolerance is not separable
  (legitimate claims of a thin triangle carry up to 3.5e-1 error).
- **Pins:** the needle covers nothing (CPU); the GPU parity golden for
  a needle mesh agrees with the CPU; a well-conditioned grid is
  untouched; the threshold boundary is pinned on both sides; the two
  lookup paths agree on a hostile corpus.
- **Gate:** clippy + both crates' tests + the CPU/GPU parity golden.

### 1.2 The malformed-triangle policy asymmetry (the follow-up row 298 named)

- **Surface:** `crates/umber-mesh/src/fill.rs` (the fill's `pos_finite`
  filter) + `crates/umber-app/src/projection.rs` (the projector's
  treatment of a non-finite-position winner).
- **The question:** the fill SKIPS triangles with non-finite positions;
  the projector keeps today's winner semantics (a malformed winner
  blanks its texels). Row 298 PRESERVED this deliberately — unifying it
  changes bytes.
- **Now that 1.1 lands, the asymmetry is the only remaining divergence
  between the two paths.** With the conditioning rule, the two paths
  agree on the texel set; what remains is what they DO with a malformed
  winner. One mesh-wide policy, one formula, both sides.
- **Gate:** the same.

## Wave 3 — the wave-abr tail (the one legal Adobe format)

The wave itself LANDED 2026-11-08 (rows 268/271 + 282-285). Four items
remain open, in ascending cost:

### 3.1 `patt` pattern sections

- **Surface:** `crates/umber-brush/src/abr.rs` (+ the import mapping in
  `abr_import.rs`).
- **Why first:** the ABR container's `patt` section carries the pattern
  (tiling) data the `desc`/`samp` readers already ignore; a brush that
  imports without its pattern is a brush that does not look like itself.

### 3.2 v8+ descriptor-only files

- **Surface:** the same two files.
- **The premise, DISPROVED (resolved by analysis, row 333):** the plan
  claimed "a descriptor-only ABR (no `samp` block) is a legal ABR that the
  current reader refuses". The 2026-11-10 analysis found v8/v11 are
  **unattested** in the public record and that "descriptor-only" is a
  content class, not a header number — a v6.2 file with zero samples
  already imports. See
  `docs/research/2026-11-10-abr-v8-descriptor-analysis.md`.
- **What landed instead (2026-11-10, `041b0796`):** the per-brush failure
  path was hardened — a brush with no usable descriptor is skipped and
  counted (`AbrFile::skipped_brushes`) instead of aborting the whole file.
  v8/v11 stay refused as unattested.

### 3.3 Dynamics → engine wiring

- **Surface:** `crates/umber-brush/src/abr.rs` + the engine params
  mapping (`crates/umber-brush/src/lib.rs` or the engine-params module).
- **Landed 2026-11-10 (`3079e4cb`):** `szVr` jitter → `Jitter.size`,
  minimum → a `radius_curve` floor, steps/control counted as
  `dynamics_unmapped`. No fade parameter was invented; a fade would be a
  new engine param and its own kill.

### 3.4 Cross-library stamp dedup (blake3)

- **Surface:** the import path + the asset store's dedup.
- **The lowest priority of the four**: it saves disk, not correctness.
  It also touches the asset store, a wider surface than the other three
  — take it LAST.

- **Surface:** `crates/umber-core/src/smart.rs` (the schema) +
  `crates/umber-app/src/document.rs` (the smart-material apply path) +
  the inspector panel + both `.ftl` catalogs.

  schema + the two shipped materials, 4.1b the UI.

  check (screenshot + pixel count), not just the suite.

### 4.2 `wave-community-templates` — 10 curated `.umber` templates

  ten curated templates that ship with the app.
- **Surface:** `assets/templates/` + whatever loads them.
- **The gate:** authoring ten assets is a design task with a partner
  taste dimension — the ROADMAP calls it "the fastest show-off", which
  is also the most subjective. Draft the SET and the naming, then fill.

### 4.3 `wave-procedural-history` — graph topology edits as undoable commands

- **Surface:** the graph journal + the History panel's third arm.
- **The state:** L6 (the unified timeline) landed 2026-10-27, so the

## The standing order of operations (every wave)

1. Scout: read the queue's max row, the live locks, the tree's dirty
   files, the CI state. Never carry a row number in memory.
2. Brief: the design brief lands FIRST (`docs/loop/briefs/`), with the
   measured numbers and the rejected alternatives in it.
3. Lock: take the kill-lock BEFORE the first edit.
4. Dispatch: the claw writes the code, pattern-ports the logic only,
   never copies code or prose.
5. Gate 1: the dragon's battery (clippy `-D warnings`, the crates'
   tests, `check-layers.py`, `scorecard.py --check`, rustfmt) + an
   INDEPENDENT verification (the claw's word is not the evidence).
6. Report: the kill report, the queue row, the vault note.
7. Gate 2: `dcommit.py` (path-limited, with the locks) → `safe-push.py`
   **BARE** (never wrapped in an outer flock — it takes
   `/tmp/umber-cargo.lock` itself) → the release CI (`scripts/release-ci.sh`).
8. Release the lock in the same step as the commit.

**The two rules the last wave earned:**

- **A plan that states a false complexity is a bug later kills inherit.**
  A brief that asserts a cost owes a measurement.
- **A byte-identity promise is proven by fuzzing both implementations on
  hostile inputs** — and every divergence is a question about who is
  right, not an obstacle to the claim.
