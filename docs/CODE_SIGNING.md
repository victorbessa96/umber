# Code signing policy

Umber's Windows binaries are **not signed yet**. This page says how they
will be, what you can verify today, and who decides what gets signed.

## Today (v0.1.0 alpha)

- Windows shows SmartScreen's "Windows protected your PC" for an unsigned
  download. Choose **More info → Run anyway** if you trust the source.
- Every release publishes `sha256.sum` and a `.sha256` per archive (the
  shell and PowerShell installers check them for you). Verify a manual
  download against the release page:
  - Windows: `Get-FileHash umber-app-x86_64-pc-windows-msvc.zip`
  - Linux: `sha256sum -c umber-app-x86_64-unknown-linux-gnu.tar.xz.sha256`
- Releases are built by GitHub Actions (`.github/workflows/release.yml`)
  from the tagged commit of this public repository, never on a personal
  machine.

## Planned: free signing through SignPath Foundation

Umber is applying for SignPath Foundation's free open-source signing.
Once accepted:

- Free code signing provided by [SignPath.io](https://about.signpath.io/),
  certificate by [SignPath Foundation](https://signpath.org/).
- Signed binaries name **SignPath Foundation** as the publisher. SignPath
  verifies that each signed file is an automated build of this
  repository's source.
- SmartScreen can still warn on a new release until it builds download
  reputation. Signing makes that reputation carry across versions.

## Team roles

- **Committers and reviewers:**
  [repository collaborators](https://github.com/victorbessa96/umber/graphs/contributors).
  Changes from anyone else arrive as pull requests and are reviewed by a
  committer.
- **Approvers** (who may approve a release for signing): the repository
  owner, [@victorbessa96](https://github.com/victorbessa96).

Every signing request is approved by hand, one release at a time.

## Privacy

This program will not transfer any information to other networked
systems unless specifically requested by the user or the person
installing or operating it. Umber has no telemetry: the crash reporter
and the session log write only to your own state folder, and nothing is
uploaded.

## What the installers change, and uninstalling

Umber installs no services. The archives change nothing: unpack and run.

The installer scripts (generated by cargo-dist 0.32.0) make these
per-user changes, and nothing machine-wide:

- copy the `umber` binary into `~/.cargo/bin` (cargo-dist's default
  install path);
- add that directory to your PATH. The shell script edits your shell's
  rc file. The PowerShell script edits your user `Environment.Path`
  registry value. Both skip this when `UMBER_APP_NO_MODIFY_PATH=1` (or
  the PowerShell `-NoModifyPath` switch) is set;
- write an install receipt, `umber-app-receipt.json`, under your config
  directory (`%LOCALAPPDATA%` on Windows).

To uninstall:

- delete the binary, the receipt, and the PATH entry the script added;
- optionally, delete Umber's per-user state folder (logs, crash reports,
  preferences, layouts).
