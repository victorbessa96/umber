## Verification (2026-10-15)

The fixture is the crate openusd's own `CrateWriter` writes from Umber's `USDC_TRI_TEXT` (869 bytes), with one byte inverted (`b[off] ^= 0xff`). Each flip was loaded with `CrateData::open(_, safe = true)` and every field was read with `try_field`. Each run was a separate process under `ulimit -v 16 GB`. The same flipped files (generated by 0.7.0) were fed to both versions.

| # | offsets | 0.7.0 site | 0.7.0 result | 0.8.0 result |
|---|---|---|---|---|
| 19 | 36, 104, 188, 389 | `usdc/reader.rs` `ReadExt::read_vec` (`vec![T::default(); count]`, :1600) / `read_compressed` (:587, :591) | **ABORT** `memory allocation of 1–13 TB failed`, exit 134 | open `Err` (188, 389) or `Ok` with one field `Err` (36, 104) |
| 20 | 39, 75, 107, 191, 392 | same allocation sites | panic `capacity overflow` | `Err` / field `Err` |
| 21 | 351 | `usdc/coding.rs:52` `&data[offset..]` | panic `range start index 65 out of range for slice of length 15` | open `Err` |
| 22 | 358 | `usdc/coding.rs:22` `count * 2` | panic `attempt to multiply with overflow` | open `Err` |
| 23 | 200 | `usdc/reader.rs:1562` `todo!("Support lz4 chunked decompression")` | panic | open `Err` (`ReadError::unsupported` at 0.8.0 `reader.rs:1791`) |
| 24 | 408 | `usdc/reader.rs:656` `debug_assert!(!value.is_compressed())` | panic (debug only) | field `Err` (`corrupt!`, 0.8.0 `reader.rs:777`) |

The 0.8.0 sources confirm the fixes. `read_vec` does a `checked_mul` and reads the bytes before it allocates. `read_compressed` caps the output at `min(compressed_size * 255 + 64, 4 GiB)`. `decode_ints` uses `checked_mul` plus a checked `seek`. `encoded_buffer_size` uses saturating arithmetic.

## Reproducer (kept for the record; `openusd = "=0.7.0"`)

```rust
use openusd::sdf::AbstractData;

const TRI: &str = "#usda 1.0\ndef Mesh \"M\"\n{\n    float3[] points = [(0,0,0),(1,0,0),(0,1,0)]\n    int[] faceVertexCounts = [3]\n    int[] faceVertexIndices = [0, 1, 2]\n    texCoord2f[] primvars:st = [(0, 0), (1, 0), (0, 1)]\n}\n";

fn main() {
    // offsets: 36 104 188 389 (abort), 39 75 107 191 392 (capacity overflow), 351 358 200 408
    let offset: usize = std::env::args().nth(1).expect("byte offset").parse().unwrap();
    let data = openusd::usda::parse(TRI).unwrap();
    let mut out = std::io::Cursor::new(Vec::<u8>::new());
    openusd::usdc::CrateWriter::write(&data, &mut out).unwrap();
    let mut bytes = out.into_inner();
    assert_eq!(bytes.len(), 869, "writer output changed; offsets no longer apply");
    bytes[offset] ^= 0xff;
    let crate_data = match openusd::usdc::CrateData::open(std::io::Cursor::new(bytes), true) {
        Ok(d) => d,
        Err(e) => return println!("open: Err({e})"),
    };
    for path in crate_data.spec_paths() {
        for field in crate_data.list_fields(&path).unwrap_or_default() {
            if let Err(e) = crate_data.try_field(&path, &field) {
                println!("{path:?}.{field}: Err({e})");
            }
        }
    }
    println!("done");
}
```

If a regression ever needs reporting, this program plus the table above is the issue body. Run it under 0.8.0 by passing the 0.7.0-written bytes, because the offsets belong to the 0.7.0 writer's output.
